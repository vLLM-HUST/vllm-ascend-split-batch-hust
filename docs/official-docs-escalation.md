# 官方规格升查链（算子级裁决引用）

适用：NZ、融合范围、后端条件、shape 限制等算子级支持/约束/格式的裁决引用。
KB 卡自标「非算子规格确认 / diff 事实 / commit 意图」的，不得当算子合约直接引用。

按序核官方规格：

1. **本机离线官方源**：随 CANN 配套的 `torch_npu` 算子 docstring 与 `aclnnop/*.h`
   头文件（版本对齐、离线可查）。默认首选。
2. **网络查 hiascend 官方文档对应版本页**：
   - 页面所标文档/软件版本须与所查 CANN/驱动版本一致，版本不一致不得引用；
   - 存档 = **关键段落原文 + URL + 文档版本 + 访问日期**，不得只存链接
     （页面内容可变，链接本身不是证据）；
   - 第 1 步覆盖不到的类型（整表算子支持列表、硬件白皮书、release notes、
     调优指南）直接走本步，不必先尝试第 1 步。
3. **实现仓源码**：只作实现事实，不作合约。

存档与结论：查证产物随证据落 L2；结论落 L1 修正卡（写明所查版本与升查层级）。
网络查证仅在已授权联网的环境执行；不可达时如实记录并回退第 1 步 + 实验验证。
