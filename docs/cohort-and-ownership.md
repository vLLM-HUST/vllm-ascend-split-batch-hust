# Cohort 适用域边界与归属说明

本文件明确本仓库在当前环境下的适用模型、硬件拓扑与归属原则。

---

## 1. 当前现行基准 Cohort (Qwen3.5-35B-A3B)

本仓现行端到端与服务评测基准锁定在 **Qwen3.5-35B-A3B**（不跨域外推至历史 Qwen2.5）：

| 维度 | 基准规范 | 依据说明 |
|---|---|---|
| **目标模型** | **Qwen3.5-35B-A3B** (40层: 30 GDN + 10 MoE) | 现行主基准模型，包含 GDN 与 MoE 核心热路径 |
| **硬件与拓扑** | **2×910B2，Tensor Parallelism (TP=2)** | 35B 规格在 910B2 上必须双卡并行，运行前需核验双卡空闲 |
| **底座软件栈** | Ubuntu 22.04 + CANN 9.1.0 + Python 3.12 | 容器当前运行环境 |
| **宿主版本** | vLLM Core `0.28.1` + vLLM-Ascend `0.25.1rc2` | 镜像内置运行时基线 (`based/image-baseline`) |
| **精度格式** | bfloat16 | 模型原生精度 |

---

## 2. 核心纪律与边界约束

1. **双卡与端到端约束**：Qwen3.5-35B 在 910B2 上属于 **TP=2** 拓扑，启动服务或执行压测前必须通过 `npu-smi info` 检查并确认 Device 0 与 Device 1 两张卡均处于空闲状态。
2. **禁止跨域外推**：历史 Qwen2.5 / 0.25 的测试记录仅作历史专项参考，不得与当前 0.28 / Qwen3.5 的指标直接互推。
3. **MTP 边界**：投机解码/MTP 保持 fail-closed，未适配前自动回退原生。
